# PC Wifi — مدير نقطة اتصال Windows

[English](README.md) | **العربية**

تطبيق سطح مكتب أصلي لنظام Windows لإدارة ميزة نقطة اتصال الهاتف المحمول (Mobile Hotspot). يجمع PC Wifi أدوات التحكم بنقطة الاتصال، ومتابعة الأجهزة المتصلة، وحدود السرعة والبيانات، ومراقبة حركة الشبكة، والحماية من الانقطاع في واجهة WPF واحدة.

> التطبيق مخصص لنظام Windows. يتوفر كود المصدر، ولم نضمّن الملف التنفيذي الموجود في الأرشيف لأنه أُنشئ قبل إضافة الواجهة ثنائية اللغة. أنشئ النسخة الحالية باستخدام `build.ps1`.

## المميزات

- **التحكم بنقطة الاتصال:** تشغيل وإيقاف نقطة اتصال Windows ومتابعة حالتها.
- **إعدادات الشبكة:** عرض أو تعديل اسم الشبكة (SSID) وكلمة المرور ونطاق Wi‑Fi المدعوم.
- **إخفاء الشبكة:** خيارات اختيارية لإخفاء اسم الشبكة والتحكم في إمكانية اكتشافها.
- **إدارة الأجهزة:** عرض الأجهزة المكتشفة، وتغيير أسمائها، وفصلها أو حظرها، والاحتفاظ بسجلها.
- **مراقبة البيانات:** متابعة إجمالي التنزيل والرفع وسرعة النقل المباشرة.
- **حدود الاستهلاك والسرعة:** تعيين حدود عامة أو مستقلة لكل جهاز.
- **مراقب استمرارية الاتصال:** متابعة حالة نقطة الاتصال ومحاولة استعادتها إذا أوقفها Windows أو تعريف Wi‑Fi.
- **الطاقة وبدء التشغيل:** منع سكون الكمبيوتر أثناء نشاط نقطة الاتصال، وضبط مهلة عدم وجود اتصالات، والتشغيل مع Windows، والتصغير إلى منطقة الإعلام.
- **سجل النشاط:** مراجعة الأحداث التشغيلية ونسخها.
- **المظهر واللغة:** مظهر فاتح وداكن مستوحى من Windows 11، مع إمكانية التبديل بين العربية والإنجليزية.

## المتطلبات

- Windows 10 أو Windows 11 مع دعم Mobile Hotspot.
- محول Wi‑Fi وتعريف يدعمان ميزة نقطة اتصال Windows.
- توفر مكونات .NET Framework 4.x / Windows Desktop على الجهاز.
- PowerShell لتشغيل سكربت البناء.
- صلاحيات المسؤول للميزات التي تعدّل قواعد Windows Firewall أو تطبق إعدادات QoS. قد تعمل الوظائف الأساسية دون صلاحيات المسؤول بحسب إعدادات Windows والجهاز.

يعتمد توفر بعض نطاقات Wi‑Fi والوظائف على المحول والتعريف وإصدار Windows ومصدر الإنترنت.

## بناء المشروع من المصدر

1. استنسخ المستودع أو نزّله على جهاز Windows.
2. افتح **Windows PowerShell** داخل مجلد المشروع.
3. نفّذ الأوامر التالية:

   ```powershell
   Set-ExecutionPolicy -Scope Process Bypass
   .\build.ps1
   ```

4. سيقوم السكربت بترجمة `PCWifi.cs` وإنشاء `PCWifi.exe` في المجلد الرئيسي.
5. شغّل `PCWifi.exe`. إذا احتجت إلى حظر الأجهزة أو تطبيق حدود QoS، أعد تشغيل التطبيق بصلاحيات المسؤول من خيار المسؤول داخل التطبيق.

إذا لم يكن ملف الأيقونة موجوداً، فسيشغّل سكربت البناء `GenerateIcon.ps1` لإنشائه من جديد.

## التشغيل

```powershell
.\PCWifi.exe
```

خيارات التشغيل:

- `--minimized` — بدء التطبيق في وضع مصغّر.
- `--screenshots <folder>` — تحديد مجلد حفظ لقطات الشاشة المستخدم في آلية اللقطات داخل التطبيق.

## اللغة

يُحفظ اختيار اللغة في الملف التالي:

`%LOCALAPPDATA%\PCWifi\settings.cfg`

وتكون القيمة `Language=en` للإنجليزية أو `Language=ar` للعربية. استخدم خيار اللغة في الشريط الجانبي للتبديل. لا يؤدي تغيير اللغة إلى حذف الإعدادات أو سجلات الأجهزة.

تتوفر الترجمة في عناصر التنقل والوظائف الأساسية لنقطة الاتصال والأجهزة والبيانات واستمرارية الاتصال والسجلات. قد تبقى بعض رسائل التشخيص ورسائل Windows وأسماء الأجهزة التي يرسلها الجهاز وبعض الرسائل الديناميكية الأقل استخداماً باللغة الإنجليزية.

## البيانات والصلاحيات

- تُحفظ الإعدادات وسجلات الأجهزة محلياً في `%LOCALAPPDATA%\PCWifi\`.
- يتعامل التطبيق مع واجهات Windows Mobile Hotspot، ويستخدم Windows Firewall وQoS لبعض أدوات التحكم.
- قد تتطلب ميزات الحظر وتطبيق حدود السرعة تشغيل التطبيق بصلاحيات المسؤول. اقرأ مطالبات Windows قبل الموافقة عليها.
- إخفاء اسم الشبكة لا يعني تشفيرها ولا يجعلها آمنة بمفرده. استخدم كلمة مرور قوية وإعدادات أمان Wi‑Fi حديثة.
- يعتمد اكتشاف الأجهزة والتعرف عليها على المعلومات التي يوفرها Windows ومحول الشبكة؛ لذلك قد لا يظهر اسم أو عنوان موثوق لكل جهاز في جميع الحالات.

## استكشاف الأخطاء

- **تعذر تشغيل نقطة الاتصال:** تأكد من عمل Mobile Hotspot من إعدادات Windows، وحدّث تعريف Wi‑Fi، وتحقق من وجود اتصال إنترنت مصدر.
- **لا تظهر الأجهزة المتصلة:** انتظر التحديث التالي، ثم أعد توصيل الجهاز، وتحقق من أن Windows والتعريف يعرضان بيانات العملاء.
- **الحظر أو حدود السرعة لا تعمل:** شغّل PC Wifi بصلاحيات المسؤول، وتحقق من عدم وجود تعارض مع سياسات Windows Firewall أو QoS.
- **تنطفئ نقطة الاتصال عند الخمول:** فعّل Keep-Alive Guard وخيار تعطيل مهلة عدم وجود اتصالات. قد تتجاوز بعض تعريفات المحولات إعدادات Windows رغم ذلك.
- **فشل البناء:** شغّل السكربت على Windows باستخدام Windows PowerShell، وتحقق من توفر مترجم .NET Framework ومراجع Windows Metadata التي يستخدمها `build.ps1`.
