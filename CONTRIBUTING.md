# Contributing

Thanks for considering a contribution to PC Wifi.

## Before opening an issue

- Include your Windows edition/build and Wi-Fi adapter model when relevant.
- Include the adapter driver version for hotspot or connectivity problems.
- Describe the steps to reproduce the issue and the expected versus actual result.
- Remove passwords, SSIDs, public IP addresses, MAC addresses, and other private network details from logs and screenshots.

## Pull requests

- Keep changes focused and preserve existing hotspot behavior unless the change explicitly addresses it.
- Test on a Windows machine with Mobile Hotspot support.
- For networking, firewall, startup, and power changes, explain the required permissions and failure behavior.
- Update both `README.md` and `README.ar.md` when user-facing behavior or setup steps change.
- Keep Arabic UI text readable in right-to-left layout; preserve left-to-right direction for IP addresses, MAC addresses, paths, and technical identifiers where needed.
- Do not commit generated executables, local settings, logs, or personal network information.
