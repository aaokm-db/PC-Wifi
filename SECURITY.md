# Security policy

## Reporting a vulnerability

Please do not publish exploitable security details in a public issue. Contact the repository maintainer privately using the security contact configured on the hosting platform. Include affected versions, reproduction steps, impact, and any suggested mitigation.

## Security notes

PC Wifi can change local firewall rules and network QoS settings when elevated. Only run builds you trust, review permission prompts, use a strong hotspot password, and do not treat hidden SSID mode as a security boundary.
